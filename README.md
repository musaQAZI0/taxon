# Vision Group & Co

A black-and-white version of the my-app website, preserving its routes, responsive layouts, service pages, and interactions.

## Run locally

npm run dev

## Validate

npm run lint
npm run build

The build exports the website to out/.

## Branding and contact details

The Vision Group & Co logo is in public/vision-group-logo.png, with a matching app/icon.svg.
The original site's phone numbers, email recipient, office addresses, and testimonial content are retained. Replace these with the new business details before publishing.
The contact form opens the visitor's email application; it does not send email through a server.
